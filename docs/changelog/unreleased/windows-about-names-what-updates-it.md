# Windows: Settings → About no longer credits the Store with a copy it did not install

Platforms: windows
Bump: patch

> A package with no `.appinstaller` was taken to be the Store's, so a copy installed from a bare
> bundle was told the Store keeps it current and offered a Store check that can only answer
> "nothing is waiting". The Store is now recognised by the package's signature, and a copy
> installed from a file says that nothing updates it.

**English**

```
On Windows, Settings → About no longer says the Microsoft Store updates a copy installed from a package file.
```
