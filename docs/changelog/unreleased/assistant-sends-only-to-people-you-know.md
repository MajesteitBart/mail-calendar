# An assistant sends only to people you know, from an account you exposed

Platforms: macos, windows, linux
Bump: patch

> The known-recipient guard accepted any address at the domain of one of the user's accounts,
> which on gmail.com or outlook.com is everyone there, and it read each recipient entry whole, so
> one entry holding two addresses passed on the second one's domain and was delivered to both.
> The domain clause is gone and an entry must be one bare address. A send that named no account
> also went from the app's default account, which the user need not have exposed; it now goes
> from the one exposed account, or must name one. The cost is that an assistant can no longer
> send a first message to a new colleague; the refusal tells the user to send it themselves.

**English**

```
An assistant allowed to send mail directly now sends only from an account you made available to it, and only to people you have written to or saved as contacts, no longer to anyone who shares your email domain.
```
